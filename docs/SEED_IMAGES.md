# Foto seed

Semua berkas di bawah dipakai oleh data contoh Yayasan Lentera Barokah. Foto diunduh, diperkecil menjadi sekitar 1200 piksel pada sisi terpanjang, lalu disimpan sebagai WebP. Tidak ada tautan panas ke server foto.

Lisensi Unsplash dan Pexels mengizinkan pemakaian komersial tanpa atribusi. Halaman lisensi: [Unsplash License](https://unsplash.com/license) dan [Pexels License](https://www.pexels.com/license/).

Logo dan favicon di `public/brand/` digambar untuk merek fiktif ini, bukan foto stok.
